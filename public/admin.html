Admin Dashboard Overview

Welcome to the Farewell/Howdy admin dashboard. This interface allows you to manage events, blog posts, featured videos, and venue settings for both Farewell Transmission and Howdy spaces.

Use the navigation sidebar on the left to access different sections of the dashboard.

Tip: The dashboard home page shows a quick overview of your site statistics.

Events Management

The Events section lets you create, edit, and delete events for both venues.

Creating Events

  1. Click the "+ New Event" button
  2. Fill in the event details including title, description, date, and time
  3. Select the venue (Farewell or Howdy)
  4. Upload a flyer image if available
  5. Click "Save" to create the event

Editing Events

  1. Find the event in the list
  2. Click the "Edit" button
  3. Update the event details
  4. Click "Save" to update the event
Note: Events can be filtered by venue using the dropdown at the top of the events list.

Blog Management

The Blog section allows you to create and manage blog posts that appear on the public news page.

Creating Blog Posts

  1. Click the "+ New Post" button
  2. Enter a title for your post
  3. Use the rich text editor to create your content
  4. Upload an image if desired
  5. Click "Save" to publish the post

The Rich Text Editor

The editor toolbar provides formatting options:

  • Text formatting (bold, italic, etc.)
  • Headings and lists
  • Adding links
  • Embedding images
Tip: Images in the blog editor can be resized by clicking and dragging the corners.

Featured Videos

The Featured Videos section lets you create a carousel of YouTube videos that will be displayed on the blog/news page.

Adding Videos

  1. Paste a YouTube URL into the input field
  2. Click "Add Video"
  3. Repeat for multiple videos
  4. Click "Save Featured Videos" when finished
Supported formats: The system accepts standard YouTube URLs (youtube.com/watch?v=ID), short URLs (youtu.be/ID), and embed URLs.

Venue Settings

The Venue Settings section allows you to manage venue-specific information such as business hours and menu items.

Business Hours

  1. Select the venue (Farewell or Howdy)
  2. Set open/close times for each day
  3. Check the "Closed" box for days when the venue is not open
  4. Add notes if needed (e.g., "Shows only", "Special event")
  5. Click "Save Hours" to update

Note about Howdy Hours: The public site displays Howdy as "Open for shows and special events" rather than showing specific hours. You can still set and save the hours in this admin interface, but they will only be used internally and not displayed on the public site.

Menu Management

  1. Select the venue and menu type (Food, Drinks, etc.)
  2. Add, edit, or remove menu items
  3. Click "Save Menu" to update
Note: Menu items can be organized into sections (like "Appetizers" or "Cocktails").

Import Legacy Data

The Import section allows you to import data from previous versions of the website.

Warning: Importing data may overwrite existing content. Use with caution.

Troubleshooting

If you encounter any issues while using the admin dashboard, try these steps:

Common Issues

  • Changes not appearing: Try refreshing the page or clearing your browser cache.
  • Upload errors: Ensure your image is under 5MB and in a supported format (JPG, PNG).
  • Login issues: Try clearing cookies or using a private/incognito browsing window.

Get Help

If you continue to experience issues, please contact support:

Email: help_i_broke_the_thing@distorted.work

  • What you were trying to do
  • What steps you took
